## [0.1.0] - 2025-01-01
### Added
- Initial enterprise repository release of Enterprise ETL Pipeline Studio.
- Ingestion modules for CSV, JSON, and Parquet data files and URLs.
- Polars and DuckDB profiling and contract inference engine.
- Data Quality Gates and Pandera-backed validation.
- Polars transformation pipeline.
- Single-call structured Google Gemini integration for AI Contract Advisor and Record Enrichment.
- Lineage tracking with Plotly Sankey and PyDeck geospatial visualizers.
- Custom dark glassmorphic Streamlit UI layout.
- Comprehensive deterministic test suite and GitHub Actions CI workflow.
