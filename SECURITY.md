# Security Policy

## Supported Versions
| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability
Please do not report security vulnerabilities through public GitHub issues.

Report security concerns directly to the project maintainers via email at security@example.com or through GitHub Private Vulnerability Reporting.
Response timeline: Maintainers will acknowledge reports within 48 hours and provide updates every 5 business days.
